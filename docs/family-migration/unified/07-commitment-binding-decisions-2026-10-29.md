## 4. FreshnessProfile.anchor_deadline_to_inputs - BLOCKED (safety requirement not met), Architect decision D-07
Binding is fine (`freshness` is a profile member; the flag is dumped while true). Direction is safe: true gives `D = min(opened + bound, min_i(observed_i + bound_i))`, never later than false; extensions cannot defeat a narrowed class ceiling (the class-age composer caps base + extension at the Registry value and irreversible classes are never extended). **Residual:** with the flag true and no `policy_binding`, the purpose observation and the cached-purpose snapshot are judged once at evaluation and join the deadline only when a `PolicyBinding` exists (runtime_authority.py:405-415; bounded.py:2160-2175). Example: narrowed class bound 30 s, purpose observed 30 s before evaluation (accepted), dispatch stalled 29 s: purpose age at dispatch 59 s, about 2x the Registry-narrowed ceiling. The Architect requirement is that no extension or timestamp calculation defeat a Registry-narrowed ceiling, so setting the flag alone does NOT satisfy it. Closing the window needs either a protected-evaluator edit (runtime_authority.py, own bounded PR, F3 requalification) or allowing `policy_binding` in the profile-bearing families (currently refused). Also a host with `freshness=None` cannot take the flag. Options: **A** accept and document the residual, then implement the minimal composer (design recorded in the anchor reconciliation); **B** authorise the protected-evaluator change; **C** keep blocked. Not implemented.

## 5. ActionClass.irreversible - IMPLEMENTABLE, implemented in the unified package
No protected evaluator change: the flag is read at bounded.py:2111 (`irreversible and on_unreadable != "refuse"` gives `action_class_invalid`) and :2189 (cached-grant fallback removed) and is in the profile dump. The composer only strengthens (false to true) for every action of a class, never repairs a dependent field and refuses when the HOST class has `reversibility` set, `reversible_until`/`reversal_cost` set, `on_unreadable != refuse` or non-default producer facts (`irreversible_flip_conflict`). Registry can never assert reversibility.
