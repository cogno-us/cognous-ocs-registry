# 6. Ordered PR and sprint execution plan

Status: **planning labels, not authorized sprints.** No PR below may begin before gates G-0 to G-2 are recorded ([01](01-executive-implementation-proposal.md)). Each PR is one bounded owner increment, ends in a draft PR, and is not merged automatically. PR identifiers use the prefix `EXT-` because the labels S1..S6 collide with the historical sprints S01..S06 of plan v1.1. "Maps to" names the field IDs of [03](03-field-extraction-register.md), scenario IDs from the existing catalog (referenced, not restated), or the governance contract/ledger/gap the task serves. Evidence wording for everything produced: "developer-tested, Copilot-reviewed where reviewed, not independently qualified". Nothing is merged on the strength of builder tests alone being called independent.

Stop-gate legend: **G-3** `EXT-S1-1` accepted; **G-4** R10-F-01/02/03 disposition; **G-5** rulings (D4, MC-06 G2/G3, W8-014; D6 plus encoding for `max_amount`); **G-6** independent lead designated.

## Review and merge discipline

Bounded owner increments only; one substantive review per PR; reserve additional independent technical review for code affecting authority, policy activation, canonical state or external effects (S1-6, S1-7, S4-2, S4-3). Copilot is the operator-designated code reviewer for these PRs (comment-only; cited as "Copilot-reviewed", never "qualified"); it is not evidence review or qualification. **This plan assumes no merge authority.** Plan v1.3 section 7 permits no auto-merge except separately authorized exact-head changes, and the existing standing delegations in `docs/decisions/` cover only the earlier sprints. Each PR in this plan needs its own explicit authorization for merge, after independent review and green exact-head checks. A new issue is a V1 blocker only if it violates an approved scenario, a mandatory security boundary or an explicit gate; otherwise it is marked DEFERRED with owner and impact.
