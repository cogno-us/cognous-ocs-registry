## Status vocabulary (binding)

- `PASS_RECORDED`: a named historical case passed at the g8-r10 controller pins (Control Plane `0a41faa9`, Runtime `ec728da6`), not at `7a4bcd40`/`c5e97e87`. The scenario row stays INCONCLUSIVE; there is no scenario-level PASS.
- `KNOWN_LIMIT_ASSERTED` (C11, C07, C10, D07): a test that asserts a limit; never a PASS or protection.
- `NO_TEST` 602, `NOT_RUN` 67 (all 656 Wiki-derived cases are NOT RUN; collection is not execution). D01, D03, D04 stay INCONCLUSIVE.
- `BUILDER_TESTED`: registry-repo tests (S01, S03 to S06, R08); the builder wrote code, oracle and harness. The recorded 373 passed at the S06 head are builder self-runs, not current-head results.
- Existing expectations are preserved and are not edited to obtain a pass. One expectation (QS13 in `docs/r08-s01/qualification-spec.md`) was amended after the candidate's behaviour was seen: it is developer evidence only and the independent lead must re-adjudicate and freeze it before executing.

## Common independence rule (applies to every gate)

(i) Expectations written by the independent oracle author from the contract, manifest and source before any implementation result for that gate is shown to them. (ii) Expectations, candidate pins and a spec digest frozen in a dated qualification-repo commit before execution. (iii) Amendments dated and recorded, never made to obtain a pass. (iv) Executed or supervised by the independent lead at exact source pins. (v) Synthetic data only; no network, paid or credentialed calls. (vi) A mismatch against a resolved expectation is FAIL; an unresolved mapping is BLOCKED. (vii) A mutation leg per refusal family (disable one refusal check; the case must fail). (viii) The verdict transfers only to the exact candidate and profile. Race and clock gates need repeated runs with raw output retained; one run is not evidence.

## Independence given GAP-G4-13 (no independent qualification owner is designated)

1. **S5 entry** requires a written designation of an independent lead (name; independence statement from builder, architect, oracle author and Copilot). Without it S5 runs only in PREPARE mode: oracles drafted, predeclared and hash-frozen, executed by builder-side inspection, every output labelled "builder-side inspection; Tier 1 not qualified", never counting toward V1-M8, CA04 or CA23.
2. **Roles stay separate:** oracle author (blind), builder (never edits expectations), runner (retains raw output), evidence reviewer (separate from all three), final adjudicator (the operator). The architect holds none of the first four for Tier 1.
3. **Only the designated lead can write a Tier 1 verdict.** If none is designated by S5 exit, the candidate reads "OCS-only V1: NOT INDEPENDENTLY QUALIFIED", operator-held, and GAP-G4-13 stays open. Wording is not softened to compensate.
4. **Escalation:** if no lead can be secured, that single fact goes to the operator as a change to an authorized boundary (plan v1.3 section 8), not as a technical question.
5. **Copilot** is the operator-designated code reviewer (review state COMMENTED, cannot approve, block or execute batteries). It is not evidence review, test execution or qualification. The operator's recorded statement "no second llm for now" means independent evidence review is not performed today and must be recorded as such.
