## Status vocabulary (binding)

- `PASS_RECORDED`: a named historical case passed at the g8-r10 controller pins (Control Plane `0a41faa9`, Runtime `ec728da6`), not at `7a4bcd40`/`c5e97e87`. The scenario row stays INCONCLUSIVE; there is no scenario-level PASS.
- `KNOWN_LIMIT_ASSERTED` (C11, C07, C10, D07, and the new LIM-A1 for Route A): a test that asserts a limit; never a PASS or protection.
- `NO_TEST` 602 and `NOT_RUN` 67 are crosswalk-row evidence statuses. Separately, no Wiki-derived case has a recorded run. D01, D03, D04 stay INCONCLUSIVE.
- `BUILDER_TESTED`: registry-repo tests (S01, S03 to S06, R08); the builder wrote code, oracle and harness. The recorded 373 passed at the S06 head are builder self-runs, not current-head results.
- `PROPOSED`: MVP v7 rows are a builder proposal awaiting independent review; neither PASS_RECORDED nor evidence of anything registry-related.
- PREPARE words: `DRAFTED`, `PREDECLARED`, `FROZEN_PENDING_LEAD`, `BUILDER_INSPECTED`, `BLOCKED`, `NOT_RUN`.
- Existing expectations are preserved and are not edited to obtain a pass. One expectation (QS13 in `docs/r08-s01/qualification-spec.md`) was amended after the candidate's behaviour was seen: it is developer evidence only and the independent lead must re-adjudicate and freeze it before executing.

## Common independence rule (applies to every gate)

(i) Expectations written by the independent oracle author from the contract, manifest and source before any implementation result for that gate is shown to them. (ii) Expectations, candidate pins and a spec digest frozen in a dated qualification-repo commit before execution. (iii) Amendments dated and recorded, never made to obtain a pass. (iv) Executed or supervised by the independent lead at exact source pins. (v) Synthetic data only; no network, paid or credentialed calls; Ed25519 synthetic keys only (R9). (vi) A mismatch against a resolved expectation is FAIL; an unresolved mapping is BLOCKED. (vii) A mutation leg per refusal family (disable exactly one refusal check; the case must fail, else the control is worthless). (viii) The verdict transfers only to the exact candidate and profile. Race and clock gates need repeated runs with raw output retained; one run is not evidence. (ix) The synthetic emulator integration host lives in the registry repository (R12); the oracle author drives it and never authors it.

## Independence given GAP-G4-13 (no independent qualification owner designated): PREPARE-only handling

1. **S5 entry** requires a written designation of an independent lead naming the person and an independence statement from the builder, the Architect, the oracle author, Copilot and the author of the registry emulator host (R12). Without it S5 and S6 run only in PREPARE mode.
2. **May produce:** predeclaration documents; oracle specifications and expectations marked `proposed`; digest-frozen expectation files and candidate-pin placeholders; the run protocol; the qualification-repo suite and workflow; builder-side inspection runs; PR cards; gap lists. Every output carries "builder-side inspection; Tier 1 not qualified".
3. **May not produce or claim:** a PASS, FAIL or verdict for any gate; the words qualified, independently qualified, certified or accepted; any count toward V1-M8, CA04 or CA23; that Route A is protected or that both routes are; any claim for `max_amount`; builder tests, Copilot review or the emulator host as independent evidence; edits to an expectation after a result was seen; real keys, network, paid or credentialed calls; an "OCS-only V1" wording other than "NOT INDEPENDENTLY QUALIFIED"; release, publication or production inferences.
4. **Roles stay separate:** oracle author (blind), builder (never edits expectations), runner (retains raw output), evidence reviewer (separate from all three), final adjudicator (the operator). The Architect holds none of the first four for Tier 1. Only the designated lead can write a Tier 1 verdict.
5. **Entry criteria to leave PREPARE (all, recorded, operator-adjudicated):** written designation and independence statement; operator confirmation of the eight-field V1 and the rulings recorded before the freeze; the S4-0 ADR adopted so dispositions for NX-03/04/08 and stale sync exist (a missing disposition is BLOCKED, never waived); the lead re-derives or attests every PREPARE-drafted expectation (blind rule) and re-adjudicates QS13; a dated freeze commit in the qualification repo (expectation digest plus candidate SHAs, synthetic fixtures, Ed25519 synthetic keys); a separate evidence reviewer or "not performed" recorded (the operator's statement "no second llm for now" means independent evidence review is not performed today); leaving PREPARE does not upgrade earlier outputs: every gate is executed afresh by the lead at the frozen pins, with repetitions for race gates.
6. **If no lead exists at S5 exit,** the candidate status is "NOT INDEPENDENTLY QUALIFIED", GAP-G4-13 stays open, and that single fact goes to the operator as a boundary change, not as a technical question.
7. **Copilot** is the operator-designated code reviewer (review state COMMENTED; it cannot approve, block or execute batteries). It is not evidence review, test execution or qualification.
